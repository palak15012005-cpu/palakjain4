# Palak Jain Portfolio

## Files
- `index.html` — page structure and content
- `css/style.css` — all styles, colors, responsive layouts, animations
- `js/script.js` — theme toggle, mobile navigation, skill rendering, counters, and other interactions
- `assets/` — place images or downloadable files here (currently empty)

## Run locally
Open `index.html` in your browser. The page uses Google Fonts over the internet; all other current assets are inline SVGs.

## Important notes
- The contact form currently demonstrates a front-end success state only; it does not send email to a server.
- The resume button is a placeholder. Add your resume PDF and update the button link/JavaScript before publishing.
- Review the portfolio's experience, metrics, certifications, email, phone, education, and project links before publishing to ensure they accurately reflect your real background.
